1. Executive Summary & Value Proposition

GrowthPilot is an autonomous multi-agent AI system built for modern e-commerce brands. Traditional analytics dashboards leave a critical gap: store owners must manually analyze metrics, guess promotional pricing, draft marketing copy, set up discounts, and calculate A/B test results.

GrowthPilot closes the loop from analytics to action. It operates 24/7 as an intelligent growth loop:

🔍 1. Continuous Opportunity Discovery

Ingests store orders, customer segments, cart abandonments, and churn metrics to spot hidden revenue leaks and cross-sell bottlenecks.

🎯 2. Deterministic Scoring & Prioritization

Ranks opportunities by expected revenue impact, model confidence, and urgency factor to execute only high-ROI plays.

🛡️ 3. Profit Guardrails & Dynamic Bands

Calculates margin-safe dynamic discount bands based on product margins and CLV, preventing margin erosion.

⚡ 4. Live Razorpay Execution & Learning

Generates real Razorpay payment links & orders, captures webhooks via Redis queues, and analyzes post-campaign statistical lift.

2. Multi-Agent Orchestration Engine

The system employs four specialized agents working in a coordinated state graph governed by a central Orchestrator.

Agent Source Module Primary Function Output Artifact
Insight Agent backend/app/agents/insight_agent.py Analyzes cohort segmentation, churn risks, product trends, and funnel abandonment. Structured Insights
Growth Decision Agent backend/app/agents/decision_agent.py Scores and prioritizes opportunities using formula: Impact × Confidence × Urgency. Ranked Opportunities
Campaign & Pricing Agent backend/app/agents/campaign_agent.py Computes dynamic discount bands, drafts persuasive copy, and calculates expected ROI. Campaign Proposals
Experiment & Learning Agent backend/app/agents/experiment_agent.py Measures conversion lift (A/B testing), calculates z-scores/p-values, and adjusts confidence. Experiment Analysis

Autonomous Feedback & Learning Loop

When a campaign is approved and executed, the Experiment Agent tracks real conversion rates against baseline cohorts. If conversion lift is statistically significant (p < 0.05), future Decision Agent confidence is rewarded. If Razorpay returns a payment.failed event, an automated penalty (-0.08) is applied to prevent recurring low-converting strategies.

3. Key Technical Innovations (Phase 2)

1. Supabase Postgres & Multi-Tenant Row Level Security (RLS)

Every entity (customers, products, orders, insights, campaign_proposals, executions, audit_logs) is scoped by tenant_id. Configured with Alembic migrations and Postgres RLS policies to guarantee strict data isolation across merchants. Dual-engine architecture falls back to SQLite locally with zero configuration.

2. Redis Event Queue & Asynchronous Worker

Razorpay webhooks (payment.captured, payment.failed, order.paid) are published to the Redis event queue (growthpilot:events:queue). A background worker thread drains the queue without blocking webhook HTTP responses, guaranteeing sub-50ms endpoint latency.

3. Sliding-Window IP Rate Limiting & High-Throughput Caching

Protects critical endpoints (/api/webhooks/razorpay: 30 req/min, /api/campaigns/{id}/approve: 15 req/min). Employs Redis TTL caching (30–60s) for high-frequency overview endpoints with event-driven cache invalidation upon campaign execution.

4. Deterministic Dynamic Discount Band Guardrails

Replaces static discount caps with mathematical margin protection: compute_discount_band(product, segment, opportunity) -> (min_pct, max_pct, recommended_pct). Takes product gross margin (margin_pct), inventory urgency factor, and customer CLV into account so discounts never erode profit margins.
